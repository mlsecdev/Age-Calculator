# Age Calculator

A lightweight, client-side age calculator built with vanilla HTML, CSS, and JavaScript. Users enter their birthdate and instantly receive their exact age in years, with a clean and friendly user interface.

---

## Demo

Live preview: [mlsecdev.github.io/Age-Calculator](https://mlsecdev.github.io/Age-Calculator) *(enable GitHub Pages from repo settings)*

---

## Features

- Birthdate input with MM/DD/YYYY format support
- Instant age calculation on button click
- Handles edge cases: empty input, invalid dates, and future dates
- Animated result display with friendly output messaging
- Fully responsive layout for desktop and mobile
- No dependencies, no frameworks, no build tools required

---

## Tech Stack

| Layer      | Technology            |
|------------|-----------------------|
| Markup     | HTML5                 |
| Styling    | CSS3 (inline)         |
| Logic      | Vanilla JavaScript    |
| Font       | Google Fonts (Poppins / Nunito) |

## Getting Started

No installation required.

```bash
# Clone the repository
git clone https://github.com/mlsecdev/Age-Calculator.git

# Open in browser
cd Age-Calculator
open index.html
```

Or simply download `index.html` and open it in any modern browser.

---

## Usage

1. Enter your birthdate in the input field (MM/DD/YYYY)
2. Click the **Calculate** button
3. Your current age will be displayed below the input
